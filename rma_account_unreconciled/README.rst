This module adds a new fields "Unreconciled" on RMA Order Lines, that
allows to find Order's with unreconciled journal items related.

**(Features pending of new version)** This module allows to reconcile
those Orders in a single click. In accounting settings users will be
able to set up a specific account for write-off.
